Backup e restauração

O arquivo JSON salva vendas, histórico, produtos, estoque, movimentações, metas e fechamentos.

Restaurar substitui os dados deste navegador. Guarde o arquivo em outro local.

O Excel é uma cópia para consulta e arquivo, não um banco sincronizado. Exporte novamente após novas vendas.

🔐 Senha do dono

Não configurada

A senha do dono libera todos os menus e autoriza ações administrativas. Na atualização, sua senha antiga do caixa continua sendo a senha do dono. O caixa também pede senha para abrir, fechar e sair da tela expandida.

Não é login de servidor: usuários com acesso ao armazenamento do navegador podem modificar os dados. Se perder a senha, não há recuperação automática. Guarde seus backups em local seguro; eles contêm o verificador de senha.

👤 Acesso dos funcionários — somente PDV

Desativado

Crie uma senha diferente para os funcionários. Eles poderão usar apenas o PDV, registrar vendas e emitir comprovantes. Estoque, serviços, salários, financeiro, metas, histórico, relatórios, Excel, backups e configurações ficam no perfil do dono.

Se o funcionário fechar o caixa, o registro será salvo; somente o dono poderá abrir os relatórios e gerar o backup. Troque de usuário para liberar o painel completo com a senha do dono.

Armazenamento e limitações

O GitHub Pages hospeda apenas o site; não recebe dados da papelaria. Os registros ficam neste navegador. Não use modo anônimo e não limpe os dados do site. Os perfis são uma restrição de interface local, não autenticação segura de servidor: quem tem acesso ao navegador e às ferramentas de desenvolvimento pode consultar ou alterar o armazenamento. Para proteção real de salários e finanças, use banco de dados com permissões e login no servidor.
